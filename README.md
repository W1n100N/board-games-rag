## ✨ Возможности

### 🔍 **Интеллектуальный поиск**
- Векторный поиск по тексту правил с использованием мультиязычных эмбеддингов
- Автоматическая оптимизация запросов для повышения релевантности
- Извлечение источников информации (какая игра, раздел правил)

### 🤖 **Генерация ответов**
- Интеграция с Google Gemini 2.0 Flash
- Ответы строго на основе загруженных документов (без галлюцинаций)
- Поддержка русского языка

### 🛡️ **Безопасность и контроль**
- Фильтрация вредоносных запросов (читерство, эксплойты)
- Rate limiting для работы с бесплатными API
- Проверка релевантности ответов

### 📊 **Мониторинг и аналитика**
- Полная трассировка всех запросов через Langfuse
- Метрики времени ответа, источников, статусов
- История диалогов

### **Автоматизация**
- Скачивание правил с официальных источников
- Пакетная обработка PDF файлов
- Кэширование эмбеддингов

cd board-games-rag

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Скачайте правила игр
python download_pdfs.py
